SSH 세션에 접속하면
여기에 파일 탐색기가 열립니다.
SSH 터널

127.0.0.1에만 열립니다. 서버가 켜져 있는 동안 유지되고 끊기면 자동 재연결합니다.

W.S.T

왼쪽 세션을 더블클릭하거나, 위의 빠른 접속에 user@host를 입력하세요.

최근 접속

    드래그 = 복사 · 우클릭 = 붙여넣기 · Ctrl+Shift+C/V
    Ctrl+Shift+P(F1) 명령 팔레트 — 세션·동작을 이름으로 검색
    Ctrl+Alt+N 새 세션 · Ctrl+Alt+W 탭 닫기 · Ctrl+Tab / Ctrl+Alt+←/→ 탭 이동 · Ctrl+Alt+F SFTP
    Ctrl+Shift+F 터미널에서 찾기 · Ctrl+Shift+S 출력 저장 · Ctrl+Alt+1~4 화면 분할 · Ctrl+휠 글자 크기
    끊긴 탭에서 R = 재접속, Enter = 탭 닫기

    준비

    새 세션

    색 라벨
    점프 호스트(SSH 게이트웨이) 경유
    고급 (접속 후 실행 · 연결 옵션 · 터미널)

    비밀번호는 원격 데스크톱 창에서 입력하거나, 세션 우클릭 → "RDP 비밀번호 저장"으로 저장해 두면 묻지 않습니다.

    Mosh는 이 PC의 WSL에 mosh가 설치돼 있어야 합니다 (서버에는 mosh-server).

    비밀번호 입력

    처음 접속하는 서버입니다

    의 호스트 키 지문을 확인하세요.

    신뢰하면 저장되고, 다음부터 키가 바뀌면 경고합니다.

    ⚠ 호스트 키가 바뀌었습니다

    의 키가 저장된 것과 다릅니다. 서버를 재설치·교체하지 않았다면 중간자 공격일 수 있으니 접속하지 마세요.
