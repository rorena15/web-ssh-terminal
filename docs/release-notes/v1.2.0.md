## W.S.T v1.2.0

### 변경 사항
- **자동 업데이트.** 실행 중 하루 한 번 새 버전을 확인해 바뀐 파일만 받아 두고, W.S.T가 종료될 때 교체합니다. 다음 실행 때 "업데이트됨" 알림이 뜹니다.
  - 접속이나 터널이 열려 있는 동안에는 교체하지 않습니다. `data/`·`logs/`(세션, 설정, 비밀번호 저장소, 로그)는 건드리지 않습니다.
  - 업데이트 파일은 서명(Ed25519)과 파일별 SHA-256을 검증한 것만 씁니다. 실패하면 원래대로 되돌립니다.
  - ⚙설정 → 자동 업데이트에서 끄거나 바로 확인할 수 있습니다.

### 알아 둘 점
- **이번 v1.2.0은 한 번 직접 설치해야 합니다.** 압축을 풀어 기존 폴더의 `W.S.T.exe`·`_internal`·`static`을 덮어쓰세요(`data/`는 그대로 두면 됩니다). 이후 버전부터는 자동입니다.
- Program Files처럼 쓰기 권한이 없는 폴더에 두면 자동 업데이트를 하지 않습니다.

### Changes
- **Automatic updates.** While running, W.S.T checks for a new version once a day, downloads only the files that changed and replaces them when it exits. The next launch shows an "updated" notice.
  - Nothing is replaced while a connection or tunnel is open. `data/` and `logs/` (sessions, settings, password vault, logs) are never touched.
  - Only update files with a valid Ed25519 signature and per-file SHA-256 are used. Any failure is rolled back.
  - Turn it off or check now in Settings (⚙설정) → Automatic updates.

### Notes
- **Install v1.2.0 by hand once.** Extract it over your existing folder (`W.S.T.exe`, `_internal`, `static`; keep `data/`). Later versions update automatically.
- Automatic updates are skipped in folders you cannot write to, such as Program Files.
