## W.S.T v1.3.0

### 변경 사항
- **메뉴를 기능별로 다시 묶었습니다.** 메뉴바는 파일 · 터미널 · 보기 · 네트워킹 · 보안 · 도움말이고, 세부 항목은 하위 메뉴(▸)로 펼칩니다.
  - 터미널: 찾기, 출력(저장·인쇄), 탭(복제·이름 바꾸기·새 창으로 분리·재접속·닫기), 입력(MultiExec·매크로), VNC 탭이면 VNC 명령.
  - 보기: 화면 분할, 터미널 글꼴·화면 글꼴(크기·글꼴 선택)을 하위 메뉴로 정리해 메뉴 길이를 줄였습니다.
  - 네트워킹: 터널 관리, 포트 스캐너, 이 PC의 열린 포트, 파일 서버(TFTP·HTTP), 원격 서버 상세.
  - 보안: SSH 키 생성, 알려진 호스트 관리, 비밀번호 저장소 관리.
  - 키보드로도 조작할 수 있습니다: ↑↓ 이동, → 하위 메뉴 열기/다음 메뉴, ← 닫기/이전 메뉴, Enter 실행, Esc 닫기. 메뉴가 열린 동안 이 키는 터미널로 가지 않습니다.
  - 기능 표시에서 끈 기능은 메뉴에서도 숨고, 항목이 모두 꺼진 묶음과 메뉴는 통째로 숨습니다.
  - 탭 우클릭 메뉴는 그대로 있고, 툴바 [도구] 버튼은 네트워킹·보안 항목을 한 번에 보여 줍니다.
- **도움말 › 사용법 추가.** 시작하기 · 터미널 · 파일 · 원격 데스크톱 · 네트워킹 · 보안 · 화면·설정 주제별 안내를 앱 안에서 볼 수 있습니다(오프라인).
- 버전 정보 창에서 실행 환경 줄을 뺐습니다. 라이선스는 버전 정보 창의 [라이선스] 버튼으로 엽니다.

### Changes
- **Menus regrouped by function.** The menu bar is now File · Terminal · View · Networking · Security · Help (shown in Korean in the app), with details in submenus (▸).
  - Terminal: find, output (save/print), tab (duplicate/rename/detach/reconnect/close), input (MultiExec/macros), and VNC commands on VNC tabs.
  - View: split layouts and terminal/UI font size and family moved into submenus, so the menu is much shorter.
  - Networking: tunnels, port scanner, listening ports on this PC, file servers (TFTP/HTTP), remote server details.
  - Security: SSH key generator, known hosts, password vault.
  - Keyboard support: ↑↓ move, → open submenu/next menu, ← close/previous menu, Enter run, Esc close. These keys do not reach the terminal while a menu is open.
  - Features hidden in Settings → Feature visibility are hidden in menus too; groups and menus with nothing left are hidden.
  - The tab context menu is unchanged; the toolbar Tools button shows the Networking and Security items together.
- **Help › Guide.** Built-in, offline how-to pages: getting started, terminal, files, remote desktop, networking, security, display and settings.
- The About window no longer shows the runtime environment line. Licenses open from the About window's License button.
