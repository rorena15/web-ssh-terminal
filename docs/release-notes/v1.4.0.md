## W.S.T v1.4.0

### 변경 사항
- **업데이트를 설치 전에 묻습니다.** 새 버전이 있으면 메뉴 아래 알림 띠에 버전과 [변경 사항] 버튼이 뜨고, 다음 중 하나를 고릅니다.
  - **지금 재시작해서 설치**: 내려받은 뒤 확인 창(열린 접속·터널이 끊긴다는 안내)을 거쳐 W.S.T를 닫고 설치한 다음 다시 엽니다.
  - **종료할 때 설치**: 내려받아 두고 W.S.T를 닫을 때 설치합니다.
  - **나중에**: 다음 날 다시 알립니다.
  - **이 버전 건너뛰기**: 이 버전은 다시 묻지 않고, 더 새 버전이 나오면 알립니다.
  - 고르기 전에는 업데이트 파일을 내려받지 않습니다(새 버전 여부와 서명된 파일 목록만 확인).
  - 알림 띠에 변경 내용 첫 줄이 보이고, [변경 사항]을 누르면 앱 안에서 이번 버전의 변경 내용 전체를 볼 수 있습니다. 변경 내용은 서명된 파일 목록에 함께 실려 오므로 서명을 확인한 내용만 표시합니다(v1.4.0 다음 버전부터 보입니다).
- **⚙설정 → 업데이트**에서 방식을 고릅니다: 알림 후 설치(기본) · 묻지 않고 자동 설치(v1.2~v1.3 방식) · 확인 안 함. 예전에 자동 업데이트를 꺼 두었다면 "확인 안 함"으로 이어집니다. [지금 확인]은 어느 방식에서든 동작합니다.
- 서명·버전·파일 해시 검증 규칙은 그대로입니다.

### 알아 둘 점
- v1.2.0~v1.3.0에서 v1.4.0으로 올라가는 이번 한 번은 예전 방식대로 W.S.T 종료 시 자동으로 설치됩니다. v1.4.0부터 설치 전에 묻습니다.
- v1.1.1 이하는 한 번 직접 설치하세요.

### Changes
- **Updates now ask before installing.** When a new version is available, a bar under the menu shows the version and a Changes button, with these choices:
  - **Restart and install now**: downloads, asks for confirmation (open connections and tunnels will close), closes W.S.T, installs, and opens it again.
  - **Install on exit**: downloads now and installs when W.S.T closes.
  - **Later**: asks again the next day.
  - **Skip this version**: never asks about this version again; newer versions are still offered.
  - Nothing is downloaded until you choose (only the version check and the signed file list).
  - The bar shows the first line of the release notes, and Changes opens the full notes inside the app. The notes travel inside the signed file list, so only signature-checked text is shown (visible from the release after v1.4.0).
- **Settings → Updates** offers Notify before installing (default), Install automatically without asking (the v1.2–v1.3 behavior), or Don't check. If you had turned automatic updates off, it stays off. Check now works in every mode.
- Signature, version, and file hash checks are unchanged.

### Notes
- Moving from v1.2.0–v1.3.0 to v1.4.0 still installs automatically on exit this one time. From v1.4.0 on, W.S.T asks first.
- Install by hand once if you are on v1.1.1 or earlier.
