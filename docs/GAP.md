## 13. "압도" 항목 (기준 도구에 없음)
- Ctrl+K 명령 팔레트: 세션·폴더·동작 퍼지 검색
- 세션 색 라벨(운영=빨강) 탭·칸 테두리
- 원격 모니터링 바(이미 있음, 기준 도구보다 상세) + 임계치 경고
- 기능 표시 설정(안 쓰는 프로토콜·도구 숨김) — 사용자 요구
- 세션 트리 키보드 완전 조작
